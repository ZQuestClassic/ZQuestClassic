1 // ZASM has goto; WebAssembly doesn't. Wasm only has structured control flow
2 // - nested block/loop/if constructs - and `br N`, which jumps to the Nth
3 // enclosing construct: a br to a `block` jumps forward to its end (break), a
4 // br to a `loop` jumps back to its start (continue). This file rebuilds a
5 // ZASM control-flow graph as nested constructs so every original jump lands
6 // on a construct it is nested inside, replacing the loop-switch (br_table
7 // dispatch) trampoline.
8 //
9 // Algorithm: dominator-tree-guided recursive translation, following Norman
10 // Ramsey, "Beyond Relooper" (ICFP 2022). Code is laid out along the
11 // dominator tree, and two kinds of blocks earn a wrapper construct:
12 //
13 // - a loop header (back-edge target) is wrapped in `loop`, so jumps back
14 // to it are brs to that loop;
15 // - a merge node (>= 2 forward predecessors) gets a `block` opened inside
16 // its immediate dominator, so every path that joins there brs forward to
17 // the block's end, where the merge node's own code is emitted.
18 //
19 // Everything else is reached from exactly one place and is simply inlined.
20 //
21 // Handles any *reducible* CFG - every loop entered only through its header -
22 // which is what guarantees those two wrappers always suffice. Irreducible
23 // CFGs (e.g. a jump into the middle of a loop) are detected by analyze()
24 // (returns false) so the caller can fall back to the loop-switch for that
25 // one function. Analysis and emission are separate steps: callers can probe
26 // reducibility without a sink, and emit later from the same analysis (see
27 // detect_yielder_regions).
28 //
29 // You bind two things:
30 // 1. StructSink -- structural WASM emission (block/loop/if/br/...). In the
31 // real backend these call wasm.emitBlock(), wasm.emitLoop(), etc. The
32 // node/target int args are only for debug validation; ignore them.
33 // 2. emit_body(b) / emit_cond(b) -- your existing per-instruction lowering:
34 // emit_body(b): emit the straight-line WASM for block b's instructions,
35 // EXCLUDING its terminating control-flow op. For an Exit
36 // block, emit_body must itself emit the trap/return
37 // (QUIT / RETURNFUNC / script-end); the structurer emits
38 // nothing after it.
39 // emit_cond(b): for a Conditional block, emit the operands + compare so
40 // that a single i32 is left on the stack (nonzero => take
41 // the `succ_true` edge).
42 //
43 // Blocks are integers [0, num_blocks). You describe each block's terminator
44 // with BlockInfo. Successors are block ids.
