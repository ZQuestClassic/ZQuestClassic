4 // Code-generation logic shared between the two native JIT backends
5 // (jit_x64.cpp, jit_a64.cpp) that must stay semantically identical even
6 // though the backends emit through different asmjit compilers. The
7 // *decisions* - what to cache, what to flush, when a dead register's write
8 // can be dropped, how the emit loop is ordered - are single-sourced here;
9 // the backends supply only the primitive emissions through small adapters.
10 //
11 // This header is included ONLY by the two backend translation units, is
12 // header-only by necessity (templates over two asmjit compiler types), and
13 // is free to have heavy includes. It is one of two shared JIT layers:
14 //
15 // jit_shared.{h,cpp} - the runtime layer: plain data types the whole
16 // engine sees (via jit.h) and the driver .cpp
17 // (compile pipeline, run loop, lifecycle).
18 // jit_codegen_shared.h - this file: compile-time codegen policy that only
19 // the backends instantiate.
20 //
21 // Rule of thumb: something the engine or driver needs goes in jit_shared;
22 // something both backends need while emitting code goes here; something only
23 // one backend needs stays in that backend.
24 //
25 // The cache adapter ("Ops") must provide:
26 //
27 // using Reg = <asmjit 32-bit GP virtual register type>;
28 // Reg new_reg32(); // fresh virtual register
