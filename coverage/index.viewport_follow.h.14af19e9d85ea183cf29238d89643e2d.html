8 // The farthest the follow logic's focus may sit from the target's center on each axis: half
9 // the viewport minus half a hero, since the target's center can get no closer than 8px to a
10 // region edge. As long as the total displacement (half the deadzone plus the lookahead
11 // offset) stays within this, the viewport is flush against a region edge whenever the target
12 // stands on one, which is the only place a scroll can start - so scrolling geometry never
13 // depends on the follow settings. Uses the base viewport height even in extended-height mode,
14 // which is merely conservative there.
